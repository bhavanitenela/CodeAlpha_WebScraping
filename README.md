# CodeAlpha Web Scraping

## Project Overview
This project demonstrates web scraping using Python and BeautifulSoup.

## Objective
The objective of this project is to extract quotes and their authors from a public webpage and store the collected data in a CSV file.

## Technologies Used
- Python
- Requests
- BeautifulSoup
- CSV

## Website Used
https://quotes.toscrape.com/

## Process
1. Send a request to the webpage using Requests.
2. Parse the HTML using BeautifulSoup.
3. Extract quotes and author names.
4. Store the scraped data in a CSV file.
5. Display the extracted data.

## Output
The scraped data is saved in `quotes.csv`.

## Files
- `web_scraping.py` – Python web scraping program
- `quotes.csv` – Scraped quotes and authors
- `README.md` – Project documentation
